# Описание сайта: страницы и действия пользователя

## Карта страниц

1. `frontend/html/index.html` - главная (входная) страница.
2. `frontend/html/algorithms.html` - рабочая страница симулятора алгоритмов.

Дополнительно у `algorithms.html` есть deep-link состояния через hash:

- `#insertion`
- `#selection`
- `#quick`
- `#binary`
- `#dfs`
- `#bfs`
- `#sandbox`

---

## 1) Главная страница `index.html`

### Что есть на странице

1. Верхняя панель с брендом `AlgoSim`.
2. Навигационные вкладки на все алгоритмы (ведут на `algorithms.html#...`).
3. Заголовок и краткое описание платформы.
4. Блок `Что изучаем` (список алгоритмов).
5. Блок `Как работать` (пошаговая инструкция).
6. Блок `Как устроено выполнение` (общая серверная цепочка API -> очередь -> воркер -> runner -> визуализация).

### Что можно делать

1. Перейти в нужный алгоритм по вкладке.
2. Ознакомиться с назначением платформы и базовым процессом работы.

---

## 2) Страница симулятора `algorithms.html`

Это основная рабочая страница, где пользователь задает входные данные, пишет код и запускает визуализацию.

## 2.1 Верхние и общие элементы

### Что есть

1. Виджет `Статус выполнения`:
   - текущий статус;
   - общий таймер;
   - этапы (очередь, компиляция, запуск, завершение и т.д.);
   - кнопка сворачивания/разворачивания.
2. Верхние вкладки алгоритмов (`insertion/selection/quick/binary/dfs/bfs/sandbox`).
3. Разделенный layout:
   - левая колонка - данные, теория, визуализация, логи;
   - правая колонка - редактор кода.
4. Вертикальный разделитель между колонками (resizer).

### Что можно делать

1. Переключать алгоритм по вкладкам (в том числе через hash в URL).
2. Сворачивать/разворачивать блок статуса.
3. Менять ширину колонок перетаскиванием разделителя.

---

## 2.2 Левая колонка: теория, данные, визуализация

### 2.2.1 Блок `Теория алгоритма`

Что есть:

1. Отдельные теоретические блоки для:
   - сортировки вставками;
   - сортировки выбором;
   - быстрой сортировки (Хоар);
   - бинарного поиска;
   - BFS;
   - DFS.

Что можно делать:

1. Читать теорию и рекомендации по корректной реализации для визуализации.

---

### 2.2.2 Блок `Песочница алгоритма` (`#sandbox`)

Что есть:

1. Переключатель шаблона: `Массив` / `Граф`.
2. Справка по API логирования для массивов.
3. Справка по API логирования для графов.

Что можно делать:

1. Переключать тип шаблона песочницы.
2. Смотреть, какие методы трассировки доступны и как их вызывать.

---

### 2.2.3 Блок `Массив`

Что есть:

1. Ручной ввод массива (через запятую/пробел/`;`).
2. Генератор массива:
   - длина;
   - минимальное значение;
   - максимальное значение.
3. Кнопки:
   - `Построить`;
   - `Сгенерировать`;
   - `Перемешать`;
   - `Очистить`;
   - `Вернуть исходный`;
   - `Скопировать массив`.
4. Поле `Искомое число` (только для `binary`).
5. SVG-сцена визуализации массива.
6. Легенда состояний элементов (compare, swap, read, write, key, min, pivot, sorted, mid, found, range).
7. Угловой мини-блок шагов (текущий/всего + текст текущего шага).

Что можно делать:

1. Задавать массив вручную.
2. Генерировать случайный массив по диапазону.
3. Перемешивать и очищать массив.
4. Возвращать массив к базовому состоянию для текущего алгоритма.
5. Копировать текущий массив в буфер обмена.
6. Для бинарного поиска задавать `target` (при этом массив принудительно держится отсортированным).

---

### 2.2.4 Блок `Граф` (для `bfs`, `dfs` и sandbox-режима графа)

Что есть:

1. Добавление вершины по метке.
2. Очистка графа.
3. Редактор матрицы смежности.
4. Управление ребрами:
   - выбор `from` и `to`;
   - добавление ребра;
   - удаление ребра.
5. Удаление вершины.
6. Выбор стартовой и конечной вершины.
7. Списки вершин и ребер.
8. SVG-канвас графа с перетаскиванием вершин.
9. Легенда графовых состояний (start/end/frontier/visited/current/path/notfound и состояния ребер).

Что можно делать:

1. Конструировать граф вручную (вершины/ребра).
2. Быстро задавать граф через матрицу смежности.
3. Выбирать старт и финиш для поиска пути.
4. Перетаскивать вершины мышью на сцене.

---

### 2.2.5 Блоки воспроизведения шагов

Что есть:

1. Кнопки:
   - `Воспроизвести`;
   - `Сброс`;
   - `Повтор`;
   - `Шаг`.
2. Базовые скорости:
   - `Обмен (мс)`;
   - `Остальное (мс)`.
3. Кнопка `Подробнее` и расширенные скорости:
   - сравнение;
   - чтение;
   - запись;
   - перемещение;
   - установка значения;
   - диапазон.
4. Чекбокс `Autoplay`.
5. Панель `Шаги алгоритма`:
   - счетчик текущий/всего;
   - range-слайдер позиции;
   - кликабельный список шагов.

Что можно делать:

1. Управлять воспроизведением анимации.
2. Перематывать анимацию по шагам.
3. Настраивать детальные скорости анимации.
4. Включать/выключать автозапуск анимации после получения результата.

---

### 2.2.6 Блок `Запуск и сообщения`

Что есть:

1. Кнопка `Экспорт raw логов` (активируется после успешного получения raw-вывода).
2. Консоль сообщений выполнения.

Что можно делать:

1. Смотреть служебные сообщения клиента (статусы, ошибки, события).
2. Экспортировать raw-логи конкретного запуска в `.log`.

---

## 2.3 Правая колонка: редактор кода

### Что есть

1. Заголовок `Редактор кода (C#)`.
2. Кнопки:
   - `Run`;
   - `Stop`.
3. Monaco Editor для редактирования кода.

### Что можно делать

1. Писать/редактировать код алгоритма.
2. Запускать выполнение через `Run`.
3. Отправлять отмену выполнения через `Stop`.

---

## 3) Поведение страницы по выбранному алгоритму

1. `insertion`, `selection`, `quick`:
   - активен блок массива;
   - активна теория выбранного алгоритма;
   - скрыт блок графа.
2. `binary`:
   - активен блок массива;
   - показывается поле `Искомое число`;
   - массив автоматически поддерживается отсортированным;
   - `Перемешать` отключена.
3. `bfs`, `dfs`:
   - активен блок графа;
   - скрыт блок массива;
   - показывается теория соответствующего графового алгоритма.
4. `sandbox`:
   - стандартный блок теории скрывается;
   - показывается блок песочницы;
   - далее пользователь выбирает режим `Массив` или `Граф`.

---

## 4) Основной пользовательский сценарий

1. Выбрать алгоритм (вкладка).
2. Подготовить входные данные:
   - массив или граф.
3. Написать/изменить код в редакторе.
4. Нажать `Run`.
5. Смотреть статус этапов выполнения и сообщения.
6. После завершения изучить анимацию:
   - шаги;
   - легенду;
   - покадровый разбор.
7. При необходимости экспортировать raw-логи.
