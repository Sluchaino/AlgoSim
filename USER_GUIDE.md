# AlgoSim: функциональность для пользователя

AlgoSim — веб‑платформа для изучения алгоритмов через запуск кода и последующую визуализацию шагов работы со структурами данных.

## Страницы

- **Главная (`index.html`)**: краткое описание проекта и быстрые ссылки на алгоритмы.
- **Симулятор (`algorithms.html`)**: теория, входные данные (массив/граф), редактор кода, запуск и анимация.

## Алгоритмы

В симуляторе доступны:

- Сортировка вставками
- Сортировка выбором
- Быстрая сортировка
- Бинарный поиск
- Поиск в глубину (DFS) — проверка существования маршрута
- Поиск в ширину (BFS) — поиск кратчайшего маршрута

## Что может делать пользователь

### 1) Выбрать алгоритм

В верхней шапке (вкладки) пользователь выбирает нужный алгоритм. От выбора зависит:

- какой тип входных данных показывается (массив или граф),
- какая теория отображается,
- какой шаблон кода будет подставлен в редактор,
- какие элементы легенды подсветок показываются.

### 2) Прочитать теорию и “методичку”

В блоке “Теория и сигнатуры” есть:

- краткое описание идеи алгоритма,
- список шагов,
- ожидаемая сигнатура функции (для удобного старта),
- пояснение по режимам (авто/контролируемая анимация) и доступным функциям трейсинга.

### 3) Выбрать режим написания алгоритма

Доступны два режима:

- **Авто‑анимация**: пользователь пишет алгоритм “как обычно”, а шаги визуализации фиксируются автоматически при чтениях/сравнениях/записях (через `TrackedList`).
- **Контролируемая анимация**: пользователь сам задаёт шаги и подсветки (через `ITracer` и `TracingExtensions`), чтобы получить максимально детальную, управляемую анимацию.

При переключении режима шаблон кода меняется на соответствующий выбранному алгоритму.

### 4) Настроить входные данные

#### Массив (сортировки и бинарный поиск)

Пользователь может:

- ввести числа вручную (через запятую/пробел/`;`) и нажать “Построить”,
- сгенерировать случайный массив (задав количество, min/max),
- перемешать массив,
- очистить массив,
- вернуть массив в исходное состояние для текущего алгоритма (“Вернуть исходный”).

Особенности:

- Для **бинарного поиска** массив автоматически сортируется; дополнительно появляется поле “Искомое число”.

#### Граф (BFS/DFS)

Пользователь может:

- добавить вершину (лейбл вводится вручную, например `A`, `B`, `C`),
- добавить **направленное** ребро `from → to` (в том числе петлю `A → A`),
- удалить ребро (по текущей паре `from → to`),
- удалить вершину (вместе со всеми инцидентными рёбрами),
- очистить граф,
- перетаскивать вершины мышью (drag & drop),
- выбрать **стартовую** и **конечную** вершины.

Ограничение запуска:

- запуск BFS/DFS невозможен, пока не создан граф и не выбраны старт/финиш.

### 5) Написать код в редакторе

Встроенный редактор (Monaco) содержит:

- готовый шаблон под выбранный алгоритм,
- “полную программу” с `Main`, чтением `stdin` и созданием входных данных,
- отдельную функцию алгоритма с соответствующим названием (например, `QuickSort`, `Bfs`, `Dfs`).

Пользователь может менять код (и/или только входные данные) и повторно запускать.

### 6) Запустить выполнение

Кнопка `Run` отправляет код и входные данные на выполнение. В правом верхнем углу отображается:

- текущий статус выполнения,
- общий таймер,
- длительности этапов (очередь/компиляция/выполнение/готово/ошибка), которые появляются по мере прохождения.

Кнопка `Stop` останавливает ожидание/проигрывание на фронтенде.

### 7) Смотреть анимацию и управлять ею

Панель управления анимацией расположена под легендой и позволяет:

- `Play` / `Pause`,
- `Reset` (сброс проигрывания),
- `Step` (пошаговый просмотр),
- включить/выключить `Autoplay`,
- менять **скорость (x)**: влияет на темп проигрывания шагов и длительность анимаций.

Анимация строится **после выполнения** кода: сначала код выполняется, затем пользователь получает шаги и уже по ним воспроизводится визуализация.

### 8) Понимать подсветки (легенда)

На странице есть легенда подсветок:

- она динамическая и показывает **только те выделения**, которые используются в текущем алгоритме и режиме,
- для массивов — подсветки сравнения/свапа/чтения/записи и метки (pivot/min/sorted/mid/found) + диапазон,
- для графа — состояния вершин (start/end/frontier/visited/current/path) и подсветки рёбер.

## Типичный сценарий работы

1. Выбрать алгоритм во вкладках.
2. Прочитать краткую теорию.
3. Настроить входные данные (массив или граф + старт/финиш).
4. Выбрать режим (авто/контролируемая анимация).
5. Запустить `Run` и дождаться завершения.
6. Смотреть анимацию, при необходимости остановить/пошагово пройти, поменять скорость, повторить запуск.
