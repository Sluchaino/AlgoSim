алгоритмы • c# • визуализация шагов

Интерактивная веб-платформа для изучения алгоритмов сортировки и поиска данных

Вы пишете алгоритм на C#, запускаете его в изолированном окружении и получаете пошаговую анимацию: чтения, сравнения, обмены, движение указателей, диапазоны поиска и итоговый результат.

Открыть симулятор Сразу к бинарному поиску

Что доступно

  • Сортировка вставками
  • Сортировка выбором
  • Быстрая сортировка
  • Бинарный поиск
  • Поиск в глубину (DFS)
  • Поиск в ширину (BFS)

Для массивов используется TrackedList, для графов — ввод структуры графа и маршрута.

Как запускать

  1. Выберите алгоритм и задайте входные данные.
  2. Измените шаблон кода под вашу реализацию.
  3. Нажмите Run и дождитесь завершения этапов.
  4. Разберите таймлайн шагов и анимацию.
  5. При необходимости экспортируйте raw-логи выполнения.

Как это работает внутри

Запуск разделен на API, очередь сообщений, воркеры компиляции и раннер выполнения. Код исполняется в изолированном контейнере с ограничениями ресурсов, а фронтенд строит визуализацию по trace-событиям из raw-логов.

Такой пайплайн делает запуск воспроизводимым, безопасным и удобным для обучения.
