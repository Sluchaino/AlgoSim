AlgoSim — платформа для изучения алгоритмов на C#

Здесь можно писать алгоритмы на любом языке, отправлять код на выполнение и получать визуализацию структур данных. Визуализация строится после выполнения программы — без real-time зависимостей от интерфейса.

Что изучаем

  • Сортировка вставками
  • Сортировка выбором
  • Быстрая сортировка
  • Бинарный поиск
  • Поиск в глубину (DFS)
  • Поиск в ширину (BFS)

Для массивов используется TrackedList, для графов — JSON со списком смежности.

Как работать

  1. Открой нужный алгоритм.
  2. Настрой входные данные: массив или граф.
  3. Напиши код с нужной сигнатурой.
  4. Запусти выполнение и дождись результатов.
  5. Изучай визуализацию шагов и итог.

Как устроено выполнение

Платформа разделена на API, очередь, воркер и runner. Это позволяет запускать пользовательский код изолированно и безопасно.

  1. API сохраняет отправку в базу и ставит задачу в очередь.
  2. Воркер забирает задачу, обновляет статус и передает код в runner.
  3. Runner выполняет код в контейнере и пишет логи.
  4. Воркер сохраняет логи и финальный статус.
  5. Фронтенд получает результат и строит визуализацию.
