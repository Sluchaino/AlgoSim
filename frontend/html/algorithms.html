Конструктор массива и редактор алгоритмов на C#

Выберите алгоритм в шапке, настройте входные данные и запустите код. Визуализация для массивов строится автоматически, без ручных шагов.

Режим написания алгоритма

В этом режиме можно писать алгоритм как обычно — визуализация подхватывает чтения, сравнения и записи.
В этом режиме вы управляете анимацией вручную: используете ITracer, TracingExtensions и кастомные шаги.

Теория и сигнатуры

Сортировка вставками

Сигнатура: static void InsertionSort(TrackedList a, ITracer t).

Идея: поддерживаем отсортированный префикс и вставляем следующий элемент, сдвигая большие вправо.

Шаги:

  1. Цикл i от 1 до a.Count - 1.
  2. Сохрани key = a[i], j = i - 1.
  3. Пока j >= 0 и a[j] > key: сдвигай a[j + 1] = a[j], уменьшая j.
  4. Запиши a[j + 1] = key.

Важно: используйте TrackedList как обычный массив — визуализация будет строиться автоматически.

Сортировка выбором

Сигнатура: static void SelectionSort(TrackedList a, ITracer t).

Идея: для каждой позиции ищем минимум справа и меняем местами.

Шаги:

  1. Цикл i от 0 до a.Count - 2.
  2. Положи min = i.
  3. Внутренний цикл j от i + 1 до конца: если a[j] < a[min], обнови min.
  4. Если min != i, обменяй a[i] и a[min].

Важно: обмены через TrackedList автоматически отображаются.

Быстрая сортировка

Сигнатура: static void QuickSort(TrackedList a, int left, int right, ITracer t).

Идея: выбрать опорный элемент и разделить массив на меньшие/большие части.

Шаги:

  1. Если left >= right — завершить.
  2. Выбери опорный элемент (например, середину).
  3. Два индекса i и j: двигаем к центру, пока элементы не нарушают порядок.
  4. Если i <= j — обмен a[i] и a[j], затем i++, j--.
  5. Рекурсивно вызови для left..j и i..right.

Важно: любые сравнения/обмены через TrackedList визуализируются автоматически.

Бинарный поиск

Сигнатура: static int BinarySearch(TrackedList a, int target, ITracer t).

Идея: массив отсортирован, сужаем диапазон поиском середины.

Шаги:

  1. Установи l = 0, r = a.Count - 1.
  2. Пока l <= r:
  3. Вычисли m = (l + r) / 2.
  4. Если a[m] == target, верни m.
  5. Если a[m] < target, смести l = m + 1, иначе r = m - 1.

Результат: вернуть индекс или -1, если не найдено.

Поиск в ширину (BFS)

Вход: JSON из stdin вида {"type":"graph","algo":"bfs","graph":{...},"selection":{"start":"A","end":"D"}}.

Идея: идем слоями от старта с очередью.

Шаги:

  1. Прочитай весь stdin, распарсь JSON.
  2. Возьми graph как список смежности, start, end.
  3. Очередь: помести start, отметь посещенным.
  4. Пока очередь не пуста: достань вершину, если это end — можно завершить.
  5. Для каждого соседа: если не посещен — отметить и добавить в очередь.
  6. Результат выведи в stdout (например, найден/не найден, длина пути).

Поиск в глубину (DFS)

Вход: JSON из stdin вида {"type":"graph","algo":"dfs","graph":{...},"selection":{"start":"A","end":"D"}}.

Идея: уходим в глубину рекурсией или стеком.

Шаги:

  1. Прочитай весь stdin, распарсь JSON.
  2. Возьми graph, start, end.
  3. Запусти DFS из start, отмечая посещенные вершины.
  4. Если достигли end, можно завершить.
  5. Результат выведи в stdout (например, найден/не найден путь).

Авто-режим: для массивов достаточно работать с TrackedList как с обычным массивом.

Чтения, сравнения и записи автоматически формируют шаги визуализации.

Контролируемая анимация: используйте встроенные функции трейсера.

  • TracingExtensions.EmitArray(t, values) — отправить массив на сцену.
  • t.Compare(i, j), t.Read(i), t.Write(i, value), t.Swap(i, j) — базовые операции.
  • t.Mark(i, "tag") и шорткаты MarkKey/MarkMin/MarkPivot/MarkSorted.
  • TracingExtensions.Range(name, l, r, tag) / ClearRange(name) и Range(l, r, tag) / ClearRanges().
  • TracingExtensions.Ptr(name, index, tag) / ClearPtr(name).
  • t.Step(note|payload) или Console.WriteLine("__STEP__" + JsonSerializer.Serialize(obj)) — свои шаги.
